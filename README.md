# Teknologi Tepat Guna — Komoditas Kopi

Website statis berbasis Next.js untuk asesmen teknologi pasca panen kopi.  
Dibuat oleh Tim Maganghub bekerja sama dengan BPVP Bandung Barat.

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build    # Output: folder out/
npm start        # Jalankan hasil build
```
